How 1-Tap Wireless Installation Works

  1. Tap the blue GET button or Install on Device (OTA).
  2. Safari will display a native system prompt: "Open this page in iTunes?" → Tap Open.
  3. iOS will confirm: "unclip12.github.io would like to install <App Name>" → Tap Install.
  4. Go to your Home Screen: the app icon appears and installs immediately!
